模型检验算法如何保证模型的语义正确性

IC3 / PDR
✓
IC3 检查的不是语法是否正确，而是证明：模型从初始状态出发的所有可达行为都满足安全性质。

从转移系统到归纳证明

Init(s) 初始状态集合
T(s, s') 一步状态转移关系
P(s) 需要保持的安全性质
F0初始状态
F11 步可达过近似
F22 步可达过近似
Fkk 步可达过近似
  • 每个 frame 都是可达状态的过近似，因此不会遗漏真实行为。
  • 阻塞 bad state 前，IC3 用 SAT/SMT 检查该阻塞是否相对归纳。
  • 加入的子句只排除已证明不可达的状态，所以不会误删真实可达状态。

为什么结论可信

报告 Unsafe

IC3 找到从 Init 出发、每一步满足 T、最终违反 P 的真实执行路径。

s0 → s1 → ... → sn
Init(s0), T(si, si+1), ¬P(sn)

报告 Safe

某两层 frame 收敛，得到覆盖所有可达状态且蕴含性质 P 的归纳不变量。

Init ⇒ F
F ∧ T ⇒ F'
F ⇒ P
一句话：IC3 的正确性来自“真实反例”与“归纳不变量”这两个可验证证据。
