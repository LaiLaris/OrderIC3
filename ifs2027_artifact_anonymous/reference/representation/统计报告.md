# 原论文Base日志中的不等式多表示统计（2026-10-12）

## 范围与口径

读取eq_can_freq_ast_asc_all786_timeout300_paper_artifact_clean中786份Base日志，按原base.csv分成706个完成实例与80个Timeout实例。不启动Kind2，不复跑基准。

扫描以#编号打印的子句块：包括候选、复制及成功泛化结果，不包括未打印的SMT内部公式。不将超时日志当完整执行过程。每个模型独立计算键，最后相加；不同模型相同文本不合并。反复打印同一子句不增加唯一关系/形式计数，但会增加出现次数与同子句重复组计数。报告重点使用关系计数和实例计数。

解析片段：整数变量、整数常量、线性加减、常数乘法、四种比较与外层否定。为判定整数不等式等价，将比较定向并化为整数非严格下界，按变量系数gcd精确收紧常数；保留阈值和方向，不合并不同边界。排除纯常量关系与不能解析的表达式。等式使用系数合并和整体符号统一，保持极性，不做gcd约分。两者计数代表这些受支持归一化规则识别出的关系，不是任意公式的完全语义分类。

## 验证

validate.py对正负比较、严格边界、整数除法边界做7项独立预期检查。全部786份日志发现的734对不等式别名均生成异或公式，Z3全部返回UNSAT。包含Timeout组多于两种表示的关系，因此配对数不等于分裂键数。脚本、逐模型CSV、所有别名实例与SMT检查均保存在本目录。

完成日志中非恒定不等式未出现解析失败；排除了12509个常量不等式出现。等式排除了22个不支持的出现。Timeout中排除了19个不支持的不等式出现。没有把常真/常假比较全部合并成一个巨大的别名组。

## 对论文的含义

数据支持限定性描述：在这些Base完成日志的仿射整数片段中，等式有明显整体表示分裂；不等式已有的比较方向较统一，剩余多表示主要是冗余+0。它为优先处理等式提供实证背景，不证明额外不等式规范化无效，也不证明方向翻转是所有旧性能变化的原因。

若以后研究不等式，单独做保持比较方向的零项清理比直接把首项系数统一为正更容易隔离影响；本次仅提出这个由数据支持的候选，不实施、不启动实验。
